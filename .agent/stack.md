# Tech Stack (Default for All Projects)

Use this stack unless the project says otherwise.

## Language
- JavaScript only (`.js` / `.jsx`). Do not use TypeScript.

## Frontend
- React + Vite
- React Router (routing)
- Axios (HTTP client)
- TanStack Query (server state)
- Zustand (client state)
- Zod (form validation)
- Tailwind CSS (styling)

## Backend
- Node.js + Express
- Zod (validate request `body`, `query`, `params`)
- JWT + bcrypt (auth, only if the project needs login)

## Database
- SQL database (MySQL or PostgreSQL). Pick one per project.
- ORM: Sequelize or Prisma. Pick one per project.

## Testing
- Backend: Jest + Supertest
- Frontend: Vitest or Jest + React Testing Library
- Manual API testing: Postman

## Tools
- Git + GitHub
- Docker + docker-compose
- ESLint + Prettier

## Rules for Changing the Stack
- Do not add a new library without a clear reason.
- If a project needs something different, write it in that project's own `AGENTS.md`. Do not edit this file.
